文字化けしないZIP

プライバシーポリシー

文字化けしないZIPは、利用者のデータを収集しません。

  • アプリはオフラインで完結します。アプリ層の HTTP クライアントはなく、解析用の外部送信はありません。
  • アカウント、広告、解析の仕組みはありません。
  • 読む・書く場所は、選んだファイルとドロップした場所だけです。
  • パスワードは処理のためにメモリへ渡します。処理後に画面側の値は空にします。ログに出しません。JavaScript の文字列を終了時に完全に消すことは保証しません。
  • サンドボックスに network.client 権限があります。WKWebView のローカル通信のためであり、利用者のデータを外部へ送る用途ではありません。

Apple および macOS は、それぞれの方針に従ってデータを収集することがあります。このアプリがそれを依頼したり、受け取ったりすることはありません。

このページは説明のための公開文です。ページを開いても、アプリから個人情報は送られません。
